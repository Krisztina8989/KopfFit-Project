# KopfFit – Interaktive Web-Anwendung für Seniorenheime

KopfFit ist eine webbasierte Quiz-Anwendung, die speziell für den Einsatz in Seniorenheimen entwickelt wurde, um die kognitiven Fähigkeiten und die Freude an der Gemeinschaft zu fördern.

---

## 🛠 Tech Stack
* **Backend:** Python, Flask
* **Datenbank:** SQLite, Jinja2 Templating
* **Frontend:** HTML5, CSS3, JavaScript

---

## 👥 Hinweis zur Entwicklung & Urheberschaft

* **Eigenständige Umsetzung (100%):** Die gesamte technische Planung, das Datenbankdesign, das Backend sowie die komplette Spiellogik wurden eigenständig von mir umgesetzt.
* **Team-Kontext:** Zu Projektbeginn gab es eine gemeinsame Grundidee in einer Schulgruppe. Die auf der Kontaktseite gezeigten Profilkarten dienen als Platzhalter für das ursprüngliche Team.
* **Fiktive Kontaktdaten:** Aus Datenschutzgründen enthalten die Profilkarten rein fiktive Daten. Die gezeigten Personen waren nicht an der technischen Entwicklung und Code-Erstellung dieser Anwendung beteiligt.

---

## 🚀 Funktionen
* Interaktive Quiz-Spiele mit benutzerfreundlicher Oberfläche
* Benutzerregistrierung und Login-Funktion
* Dynamisches Laden von Fragen aus JSON / SQLite-Datenbank
